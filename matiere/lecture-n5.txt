# Nihongo - les textes a lire du N5.
#
# Ecrits pour ce site, comme la grammaire : voir « La lecture » dans
# nihongo.py. Ils suivent Lea, une etudiante francaise arrivee a Tokyo pour
# apprendre le japonais. Un texte :
#
#   === nom-du-texte            (minuscules, chiffres, tirets ; ne jamais
#                                renommer un texte deja lu)
#   titre: {私|わたし}の{一日|いちにち}
#   fr: Ma journée
#   genre: récit                (dialogue, récit, journal, lettre, conte,
#                                article, essai, entretien, annonce)
#   intro: une phrase, en français, qui dit de quoi parle le texte
#
#   une phrase en japonais | sa traduction
#   une autre phrase | sa traduction | te-iru, kara-raison
#
#   (une ligne vide : un nouveau paragraphe)
#   {山田|やまだ}：はい、そうです。 | Oui, c'est ça.
#                               (un dialogue : qui parle, deux-points
#                                japonais « ： », puis la réplique)
#
#   ? Une question de compréhension, en français
#   + la bonne réponse
#   - une mauvaise
#   - une autre mauvaise
#
# Tout kanji porte ses furigana, {学生|がくせい}, comme dans la grammaire.
# Un troisième champ, facultatif, nomme les points de grammaire de la
# phrase que la fabrication ne trouve pas seule (elle reconnaît les
# particules et les terminaisons des verbes). Chaque mot doit pouvoir se
# toucher : un mot que ni le vocabulaire ni matiere/lecture-mots.tsv ne
# connaissent arrête la fabrication.
